# تبلیغات و معرفی خدمات RecoveryBot

RecoveryBot برای ثبت یادداشت‌های غیرحساس و heartbeat مجاز دستگاه طراحی شده است. تبلیغات احتمالی باید فقط خدمات واقعی نصب، پشتیبانی، آموزش استفاده و نگهداری را معرفی کند.

ممنوع: وعده بازیابی قطعی حساب، دورزدن احراز هویت، حدس رمز، فروش دسترسی، جمع‌آوری رمز/کد یک‌بارمصرف/کلید خصوصی یا تبلیغ ابزارهای نفوذ. هیچ داده دستگاه یا کاربر برای هدف‌گیری تبلیغاتی فروخته نمی‌شود.

هر معرفی حمایت‌شده باید برچسب تبلیغاتی، متن بررسی‌شده و تأیید مدیر داشته باشد. این پوشه سامانه انتشار یا درآمد فعال ایجاد نمی‌کند.
